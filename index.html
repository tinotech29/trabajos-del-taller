HTML

HTML (HyperText Markup Language) es el lenguaje estándar utilizado para estructurar y presentar el contenido de las páginas web. Utiliza un sistema de etiquetas (tags) para organizar elementos como encabezados, párrafos, imágenes, enlaces y multimedia, actuando como el "esqueleto" básico de cualquier sitio web.

CSS

CSS (Cascading Style Sheets o Hojas de Estilo en Cascada) es el lenguaje utilizado para definir la presentación visual y el diseño de documentos estructurados con HTML. Controla aspectos como colores, fuentes, tamaños, márgenes y posicionamiento, separando el diseño del contenido para crear sitios web atractivos, responsivos y fáciles de mantener. 

javascript

JavaScript (JS) es un lenguaje de programación ligero, interpretado y basado en prototipos, esencial para crear sitios web interactivos y dinámicos. Es el estándar del lado del cliente en navegadores, permitiendo animaciones, validación de formularios y actualizaciones de contenido sin recargar la página. Además del frontend, se utiliza en el backend con Node.js y para aplicaciones móviles
