Git

Git es un sistema de control de versiones distribuido. En términos sencillos, es un programa que registra todos los cambios realizados en el código de un proyecto a lo largo del tiempo, permitiendo recuperar versiones anteriores, comparar estados y colaborar con otras personas de forma segura y ordenada.

¿Para qué sirve?

  • Historial de cambios: Funciona como una "máquina del tiempo". Si modificas algo y el proyecto deja de funcionar, puedes volver fácilmente a una versión anterior estable.
  • Trabajo colaborativo: Permite que varios programadores trabajen en el mismo archivo al mismo tiempo sin sobrescribir el trabajo de los demás.
  • Ramas (Branches): Permite crear "copias aisladas" del código para experimentar, añadir nuevas funciones o corregir errores sin alterar la versión principal.

GitHub

GitHub es una plataforma en la nube y red social para desarrolladores donde se almacena y comparte código fuente. Funciona como un portafolio digital y una herramienta colaborativa que permite gestionar versiones de proyectos de software, realizar copias de seguridad y trabajar en equipo de forma remota.

  • Control de versiones con Git: GitHub utiliza el sistema Git. Esto significa que funciona como una "máquina del tiempo" para tus archivos: registra cada modificación realizada, permitiendo volver a versiones anteriores, comparar cambios y crear diferentes ramas de desarrollo para probar nuevas ideas sin dañar el proyecto original.
